# Аккордеон

Группа раскрываемых вопросов и ответов. Можно разрешить несколько открытых пунктов или только один.

## Слоты

| Компонент / слот | Что передавать |
| --- | --- |
| `sunmar-accordion` / по умолчанию | Непосредственные `sunmar-accordion-item` |
| `sunmar-accordion-item` / `header` | Непустой заголовок: текст в `<span>` или другом элементе без вложенных кнопок и ссылок |
| `sunmar-accordion-item` / по умолчанию | Содержимое ответа, например `<p>` |

## Атрибуты

| Компонент / атрибут | Варианты / по умолчанию | Назначение |
| --- | --- | --- |
| Группа / `mode` | `multiple` (по умолчанию), `single` | Несколько открытых пунктов или не более одного |
| Группа / `faq` | Присутствует / отсутствует | Создать JSON-LD FAQPage из текста вопросов и ответов; по умолчанию выключен |
| Пункт / `open` | Присутствует / отсутствует | Раскрыть ответ; по умолчанию закрыт |
| Пункт / `disabled` | Присутствует / отсутствует | Запретить пользовательское переключение; открытый ответ остаётся видимым |

Логические атрибуты работают по присутствию: для выключения удалите атрибут, а не задавайте `"false"`.

## Внешнее JS-управление

```js
const accordion = document.querySelector('sunmar-accordion');
accordion.mode = 'single';
accordion.faq = true;
const item = accordion.querySelector('sunmar-accordion-item');
item.open = true;
item.disabled = true; // Программное изменение open остаётся доступным.
```
