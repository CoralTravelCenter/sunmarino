# Контракт sunmar-modal

## Назначение и структура

Модальное окно для действия, требующего временно заблокировать взаимодействие с остальной страницей. Для обычной дополнительной информации используйте немодальный блок.

Структура: overlay, dialog, заголовок с кнопкой закрытия, содержимое, необязательные действия. Содержимое остаётся в light DOM. Slots: `title`, default, `actions`. Пустой actions скрывает footer. Без заголовка используется «Диалог»; задавайте содержательное имя.

## API и миграция

| Прежний API | Новый API |
| --- | --- |
| `close-on-esc="false"` / `closeOnEsc = false` | `disable-close-on-esc` / `disableCloseOnEsc = true` |
| `close-on-backdrop="false"` / `closeOnBackdrop = false` | `disable-close-on-backdrop` / `disableCloseOnBackdrop = true` |
| `sunmar-open` | `sunmar-modal-open` |
| `sunmar-close` | `sunmar-modal-close` |

Старые имена не поддерживаются. Новые флаги выключены по умолчанию: фон и Escape закрывают окно. Boolean-атрибуты используют присутствие, поэтому `disable-close-on-esc="false"` тоже отключает Escape. Для включения удалите атрибут.

`open` — boolean-свойство с отражением в атрибуте. Методы: `show()`, `hide()`, `toggle()`. Обновление происходит в цикле Lit. Повторный show открытого окна не создаёт повторное событие. События сообщают об изменении состояния, имеют bubbles/composed=true и не содержат payload. Экспортируемые константы: SUNMAR_MODAL_OPEN_EVENT и SUNMAR_MODAL_CLOSE_EVENT. Начальное закрытое состояние не создаёт close. Удаление из DOM освобождает ресурсы без изменения open и без события close.

## Доступное имя и фокус

Приоритет имени: непустой `aria-label`, текст элементов из `aria-labelledby` в области DOM самого компонента, внутренний заголовок. Несколько ID объединяются пробелом. Для внешних ID текст передаётся внутреннему dialog как aria-label; изменения текста и ID наблюдаются. Это текстовое имя, без вычисления полной accessible-name семантики ссылочных элементов.

Внутренний section имеет role=dialog и aria-modal=true. Начальный фокус: autofocus среди доступных элементов, первый элемент содержимого, кнопка закрытия, dialog. Tab/Shift+Tab замыкаются на границах порядка отображаемых slots и открытых Shadow DOM. Используйте естественный порядок и tabindex 0/-1; положительный tabindex, закрытые Shadow DOM и переходы внутрь iframe не входят в поддерживаемый контракт фокусировки.

Escape обрабатывает только верхнее окно. После его закрытия фокус возвращается предыдущему элементу, если он подключён и не находится в inert-ветке; иначе — в оставшееся верхнее окно. Закрытие нижнего окна не переводит фокус из верхнего.

## Стек и жизненный цикл

Стек ведётся отдельно для каждого Document. Снимок inert принадлежит стеку целиком: при смене верхнего окна фон пересчитывается, после последнего закрытия восстанавливаются исходные значения. Добавленные в обычный DOM элементы фона тоже блокируются. Не меняйте inert управляемого фона вручную во время открытия.

Для нескольких соседних окон размещайте их в общем контейнере без отдельных stacking contexts предков. Порядок открытия добавляется к базовому z-index. Компонент не переносится в body и не использует top layer; transform, clipping и stacking contexts внешних предков остаются ограничением размещения.

Блокировка прокрутки использует существующий общий счётчик. Каждая активация имеет парное освобождение. Удаление до завершения show не активирует ресурсы. Повторное подключение при open=true снова активирует окно. Обработчики клавиатуры и наблюдение имени очищаются при отключении; наблюдение фона прекращается после закрытия последнего окна.

## CSS

Parts: overlay, dialog, header, title, close, body, actions. Публичные переменные: `--sunmar-modal-z-index`, `--sunmar-modal-overlay`, `--sunmar-modal-surface`, `--sunmar-modal-border`, `--sunmar-modal-title`, `--sunmar-modal-text`. Переменная `--sunmar-modal-stack-index` служебная.

Цвета, скругления, тень и типографика используют системные токены. При миграции внешний вид меняется: кнопка закрытия 40px, скругление 8px, заголовок 20px; применяются цвета и тень библиотеки. Геометрия диалога сохраняет ширину до 620px и высоту до min(90vh, 760px). Кнопка закрытия имеет focus-visible.

## Проверки

Storybook: Default, Stacked, ExplicitClose. Проверьте Tab/Shift+Tab, Escape, фон, возврат фокуса и внешний вид в браузере.

Автотесты подменяют геометрию happy-dom и функции блокировки прокрутки. Они проверяют координацию вызовов и DOM-состояния, но не заменяют браузерную проверку реальной прокрутки, порядка Tab и доступного имени скринридером.
