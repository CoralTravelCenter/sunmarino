# Слайдер

Карусель для горизонтального просмотра карточек или другого содержимого. Может переключаться в сетку на широком экране.

## Слоты

| Компонент / слот | Что передавать |
| --- | --- |
| `sunmar-slider` / по умолчанию | Непосредственные `sunmar-slide` |
| `sunmar-slide` / по умолчанию | Один корневой элемент содержимого, например `sunmar-card` |

## Атрибуты

| Атрибут | Варианты / по умолчанию | Назначение |
| --- | --- | --- |
| `slides-per-view` | Число от 1 / `1` | Количество видимых слайдов; дробное число показывает часть следующего |
| `slides-per-view-768` | Число от 1 / наследуется | Количество слайдов от ширины окна 768px |
| `slides-per-view-1024` | Число от 1 / наследуется | То же от 1024px |
| `slides-per-view-1280` | Число от 1 / наследуется | То же от 1280px |
| `slides-per-view-1440` | Число от 1 / наследуется | То же от 1440px |
| `slides-to-scroll` | Число от 1 или `auto` / `1` | Шаг переключения |
| `disabled-from` | `768`, `1024`, `1280`, `1440` / не задан | Ширина окна, с которой вместо карусели отображается сетка |
| `align` | `start`, `center`, `end` / `start` | Выравнивание позиции |
| `drag-free` | Присутствует / отсутствует | Свободное перетаскивание; по умолчанию выключено |
| `loop` | Присутствует / отсутствует | Зацикливание; по умолчанию выключено, требует достаточного количества слайдов |
| `gap` | Число от 0 / `16` | Интервал в пикселях |
| `aria-label` или `aria-labelledby` | Текст или ID заголовка | Доступное имя карусели |

Незаданный брейкпоинт наследует значение предыдущего. В Controls `none` означает отсутствие `disabled-from`.
