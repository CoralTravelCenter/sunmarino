# Контракт sunmar-slider

## Назначение и структура

Карусель для горизонтального просмотра карточек или баннеров. Используйте обычную сетку, если переключение не требуется ни на одной ширине экрана.

Default slot принимает непосредственные дочерние `sunmar-slide`. Внутри каждого слайда ожидается один корневой элемент содержимого. Компонент сохраняет узлы и обработчики потребителя, поддерживает добавление, удаление и перестановку слайдов.

Внутренняя структура: область просмотра, контейнер-slоt, кнопки назад/вперёд, пагинация и скрытый статус позиции. Публичных методов управления и пользовательских событий нет.

## Атрибуты и свойства

| Атрибут | JS-свойство | Значение и fallback |
| --- | --- | --- |
| `slides-per-view` | `slidesPerView` | Конечное число ≥ 1; по умолчанию 1; дробное значение показывает часть следующего слайда |
| `slides-per-view-768/1024/1280/1440` | `slidesPerView768/1024/1280/1440` | Та же проверка; незаданное свойство наследует предыдущую ширину, некорректное значение даёт 1 |
| `slides-to-scroll` | `slidesToScroll` | Строка `auto` или число ≥ 1, округляемое вниз; fallback 1 |
| `disabled-from` | `disabledFrom` | 768, 1024, 1280 или 1440; иные значения игнорируются |
| `align` | `align` | `start`, `center`, `end`; fallback `start` |
| `drag-free` | `dragFree` | Boolean, по умолчанию false |
| `loop` | `loop` | Boolean, по умолчанию false; фактическую возможность зацикливания определяет Embla |
| `gap` | `gap` | Конечное число ≥ 0 в px; fallback 16 |

Настройки обновляются после подключения. `disabledFrom` отражается в атрибуте, чтобы CSS и Embla переключались согласованно. Boolean-атрибуты работают по присутствию: для выключения атрибут нужно удалить.

## Состояния и жизненный цикл

- До загрузки и при ошибке Embla все слайды доступны в статической сетке без управления. Число колонок — округлённое вниз число видимых слайдов для текущей ширины.
- После инициализации Embla управляет прокруткой и позициями. Кнопки учитывают фактическую возможность прокрутки, включая режим loop.
- При числе позиций меньше двух навигация и пагинация скрыты; статус пустой. Пустой slot не создаёт заглушку.
- От `disabled-from` включается статическая сетка, управление и статус скрыты. При уменьшении ширины карусель возобновляется.
- При отключении уничтожается экземпляр Embla и снимаются его обработчики. Устаревший результат загрузки не создаёт экземпляр после удаления.
- Повторное подключение создаёт новый экземпляр и позволяет повторить загрузку после ошибки. Автоматических повторов по таймеру нет.

`embla-ready` — служебный атрибут компонента; потребитель не должен управлять им. Внешний загрузчик определён в `embla-loader.ts`.

## Доступность и клавиатура

Потребитель задаёт доступное имя через `aria-label` или `aria-labelledby`. По умолчанию компонент получает `role="region"` и `aria-roledescription="carousel"`, сохраняя явно заданные значения.

Слайды без собственного доступного имени получают «Слайд N из M». При изменении состава эти имена обновляются; при удалении очищаются только значения, которыми владеет компонент. Пользовательские непустые `aria-label` и `aria-labelledby` сохраняются.

Tab перемещает фокус по нативным кнопкам и интерактивному содержимому. Enter и Space активируют кнопки. Отдельного управления стрелками клавиатуры нет. Кнопки имеют видимый focus-visible; недоступные направления используют disabled. Пагинация обозначает текущую позицию через aria-current, статус использует aria-live="polite". Позиция карусели может объединять несколько слайдов.

## CSS API

Parts: `viewport`, `container`, `controls`, `navigation`, `prev-button`, `next-button`, `pagination`, `dot`, `status`. Внутренняя стилизация использует классы.

| CSS-переменная | Назначение |
| --- | --- |
| `--sunmar-slider-control-color` | Цвет управления |
| `--sunmar-slider-navigation-background` | Фон стрелок |
| `--sunmar-slider-navigation-outset` | Вынос стрелок от 1280px |
| `--sunmar-slider-navigation-radius` | Скругление кнопок |
| `--sunmar-slider-dot-color` | Цвет неактивных точек |

Fallback берётся из системных токенов. Ширина и отступ слайда передаются через внутренние переменные; для их настройки используйте атрибуты. Стрелки отображаются от 768px, пагинация доступна и на меньшей ширине. От 1280px нужно предусмотреть место для вынесенных стрелок.

## Проверки

Storybook: Cards, DisabledFromDesktop, SingleSlide, Empty. Для ручной проверки ошибки загрузки заблокируйте запрос Embla в браузере и перезагрузите пример: все слайды должны остаться в сетке.

Тесты с подменой Embla проверяют настройки, переключения, динамические слайды, ошибки загрузки, очистку и повторное подключение. Они не проверяют геометрию, жесты и работу настоящей Embla. Адаптивность, фокус, доступность и внешний вид требуют проверки в браузере.
