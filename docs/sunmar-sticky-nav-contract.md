# Навигация по разделам

Закрепляет ссылки при прокрутке и подсвечивает раздел, видимый на странице.

## Слоты

| Слот | Что передавать |
| --- | --- |
| `nav-link` | Непосредственные `<a href="#section-id">Название</a>`; на странице нужны разделы с соответствующими `id` |

## Атрибуты

| Атрибут | Варианты / по умолчанию | Назначение |
| --- | --- | --- |
| `top-offset` | Число в пикселях | Отступ от верха окна; без атрибута: 81px до 768px, 65px от 768px, 16px от 1024px |
| `teleport` | CSS-селектор / `.row-outer-container` | Перенести навигацию сразу после найденного элемента |
| `disable-relocate` | Присутствует / отсутствует | Запретить перенос; по умолчанию выключен |

`disable-relocate` не возвращает уже перенесённую навигацию на прежнее место. Закрепление зависит от высоты и CSS родительского контейнера.

## Внешнее JS-управление

```js
const nav = document.querySelector('sunmar-sticky-nav');
nav.topOffset = 16;
nav.disableRelocate = true;
// Для переноса:
nav.teleport = '.header-actions';
nav.disableRelocate = false;
```
