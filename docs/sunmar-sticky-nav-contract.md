# Контракт sunmar-sticky-nav

## Назначение и структура

Навигация по разделам текущей страницы с нативным position:sticky. Внутренний nav имеет имя «Навигация по разделам». Slot `nav-link` принимает непосредственно ссылки `<a href="#section-id">`. Клики, фокус, прокрутка и URL принадлежат браузеру. Компонент не перехватывает переходы и не создаёт публичных событий или методов.

## API

| Атрибут / JS-свойство | Поведение |
| --- | --- |
| `top-offset` / `topOffset` | Конечное число px; отрицательное ограничивается нулём, отсутствующее или некорректное возвращает CSS-значение |
| `teleport` | CSS-селектор цели переноса; пустое или отсутствующее значение использует .row-outer-container |
| `disable-relocate` / `disableRelocate` | Boolean по присутствию, отключает перенос; по умолчанию false |

Настройки обновляются после подключения. disable-relocate не возвращает компонент на прежнее место, а запрещает дальнейший перенос. Значение `disable-relocate="false"` тоже отключает перенос.

## Перенос и жизненный цикл

Сначала ищется ближайший совпадающий предок, затем первый узел документа. Навигация помещается сразу после цели. Себя и собственных потомков компонент целями не использует. Некорректный селектор игнорируется. Если цели нет, добавление узлов наблюдается не более пяти секунд. Смена селектора начинает новое ожидание; отключение переноса и удаление компонента отменяют ожидание и таймер.

Обычное удаление отключает наблюдателей разделов и содержимого, освобождает ссылки и восстанавливает активное состояние. Повторное подключение заново собирает связи и проверяет перенос. Собственный перенос сохраняет ресурсы до повторного подключения и не клонирует содержимое.

Sticky зависит от высоты, overflow и раскладки предков. Перенос не гарантирует фиксацию при любой внешней CSS-структуре.

## Ссылки и разделы

URL разрешается относительно baseURI документа. Подсветка работает только при совпадении origin, pathname и query с текущим документом и наличии непустого корректно декодируемого fragment. Внешние URL, другой путь/query, некорректные escape-последовательности и отсутствующие ID не участвуют. Сам переход по таким ссылкам остаётся нативным.

ID ищется в ownerDocument. Раздел может быть любым HTMLElement с соответствующим ID. Изменения href, slot, ID и состава узлов обновляют связи. Поиск не проникает внутрь Shadow DOM разделов. Изменение адреса через History API само по себе не является DOM-изменением и не запускает повторный сбор.

При нескольких ссылках на один раздел используется последняя ссылка. Если несколько разделов пересекают viewport минимум на 30% собственной площади, активным становится первый раздел в порядке карты ссылок. Если подходящих разделов нет, активная ссылка отсутствует. Высокий раздел может никогда не достигнуть 30%; изменение алгоритма подсветки не входит в этот спринт.

Неизменившиеся связи не пересоздают IntersectionObserver. Callback старого наблюдателя после переподключения или смены связей игнорируется. Без IntersectionObserver ссылки работают без автоматической подсветки.

## Владение атрибутами

Компонент управляет только классом active и aria-current ссылок. Остальные классы и атрибуты сохраняются. При выходе ссылки из slot или отключении компонента прежние значения восстанавливаются, если они совпадают с последней записью компонента. Более позднее отличающееся значение потребителя сохраняется при очистке.

## Оформление и доступность

Part: `root`. Публичные CSS-переменные: `--sunmarino-sticky-nav-z-index`, `--sunmarino-sticky-nav-bg`, `--sunmarino-sticky-nav-border`, `--sunmarino-sticky-nav-gap`, `--sunmarino-sticky-nav-top-offset`. При заданном topOffset последняя переменная управляется свойством.

CSS-offset: 81px до 768px, 65px от 768px, 16px от 1024px. Media queries используют общую карту. Фон, интервалы, размер шрифта и скругление контейнера берутся из системных токенов. Геометрия pill-ссылок и переходы сохранены. !important у slotted-ссылок сохраняет оформление навигации при подключении к странице со своими стилями ссылок.

Клавиатура нативная: Tab и Enter. Ссылки имеют focus-visible, активная — aria-current=true. Компонент не переносит фокус при смене подсветки. Пустой slot не генерирует ссылки или placeholder; контейнер сохраняет собственный padding.

## Проверки

Storybook: Default со скроллом и переносом, Dynamic с изменением ссылки и ID. Проверяются ссылка на текущую страницу, динамические разделы, очистка, повторное подключение, устаревшие callbacks, нормализация offset, поздняя цель, отмена и тайм-аут переноса.

Автотесты используют подмену IntersectionObserver: реальный sticky, процент пересечения, переходы и focus-visible нужно проверить в браузере.
