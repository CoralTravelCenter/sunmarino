# Карточка

Объединяет изображение, заголовок, текст и действия. До ширины самой карточки 1024px блоки идут вертикально, от 1024px — в две колонки.

## Слоты

| Слот | Что передавать |
| --- | --- |
| `media` | Изображение, обычно `sunmar-image`; обязательный |
| `title` | Заголовок `h2`–`h6` подходящего странице уровня; обязательный |
| `text` | Текст, обычно `<p>`; обязательный |
| `actions` | Кнопки, ссылки или `sunmar-button-group`; необязательный |

Слота по умолчанию нет. Пустой контейнер действий скрывается автоматически.

## Атрибуты

| Атрибут | Варианты | Назначение |
| --- | --- | --- |
| `reversed` | Присутствует / отсутствует | В двухколоночной раскладке переносит изображение вправо; по умолчанию отсутствует |
