# Контракт sunmar-image

## Назначение и структура

Компонент создаёт нативный `picture` в Shadow DOM. Без заполненного `srcset` он содержит только `img`; при заполненном `srcset` перед `img` добавляется один `source`. Выбор файла и загрузкой управляет браузер. Slots, собственных публичных методов и CustomEvent нет.

```html
<sunmar-image src="/photo.jpg" alt="Побережье"></sunmar-image>

<sunmar-image
  src="/mobile.jpg"
  srcset="/desktop.jpg"
  media="(min-width: 768px)"
  alt="Побережье"
  width="720"
  height="480"
></sunmar-image>
```

Пустые атрибуты `srcset media` не создают `source`. Компонент не принимает пользовательский `picture` через slot и не поддерживает несколько отдельных `source` с разными условиями.

## Attributes и properties

HTML-атрибуты и одноимённые JS-свойства поддерживают динамические изменения. JS-присваивания не отражаются в атрибуты host. Нормализация выполняется для внутренней разметки, а не для обратной записи в свойства потребителя.

| Параметр | Назначение и нормализация |
| --- | --- |
| `src` | Источник `img`. Пробелы по краям удаляются; пустое, удалённое или нестроковое значение убирает внутренний атрибут |
| `srcset` | Источники одного `source`. Пробелы по краям удаляются; пустое, удалённое или нестроковое значение убирает `source` |
| `sizes` | Подсказка размеров для `source`. Пустое, удалённое или нестроковое значение не передаётся; без `srcset` не используется |
| `media` | Условие `source`. По умолчанию `(min-width: 768px)`. Удаление или нестроковое значение восстанавливает это условие; пустая строка, включая пробелы, убирает ограничение |
| `alt` | Текст `img`, без обрезки пробелов. По умолчанию, при удалении или нестроковом значении — пустая строка |
| `width`, `height` | Конечные числа от `1`; дробная часть отбрасывается. Остальные значения и удалённые атрибуты не передаются в `img`. Через JS задаются числа, через HTML — числовые строки |
| `loading` | Только `eager` или `lazy`. Отсутствующее, удалённое или неизвестное значение не передаётся; выбор остаётся браузеру |

URL, содержимое `srcset`, `sizes` и media query передаются нативным элементам без собственного парсинга. `srcset` и `sizes` не дублируются на `img`.

## Оформление и доступность

- Публичные parts: `picture`, `img`.
- `--sunmar-image-height`: высота host, picture и img, по умолчанию `auto`.
- `--sunmar-image-object-fit`: по умолчанию `cover`.
- `--sunmar-image-object-position`: по умолчанию `center center`.
- Изображение занимает 100% ширины контейнера. Атрибуты `width` и `height` задают внутренние размеры изображения; CSS определяет отображаемую геометрию.
- Потребитель задаёт осмысленный `alt` для содержательного изображения; пустой `alt` используется для декоративного.
- Компонент не добавляет интерактивность, tabindex, role, disabled или собственное клавиатурное управление.

## Состояния и ограничения

Без `src` сохраняется `img` без атрибута источника. При изменении `srcset` добавляется, обновляется или удаляется `source`, существующий `img` сохраняется. После повторного подключения сохраняются текущие параметры. Собственных listeners, timers, observers и внешних ресурсов нет.

Состояния загрузки и ошибки остаются нативными: нет собственного placeholder, retry или автоматического перехода на `src` при ошибке загрузки выбранного `source`. `src` — fallback при выборе источника браузером, а не обработчик сетевой ошибки.

## Проверки

11 тестов happy-dom проверяют структуру, изменение и удаление атрибутов, некорректные JS-значения, размеры, loading, сохранение img и повторное подключение. Они не подтверждают фактическую загрузку файлов, выбор браузером ресурса или визуальный результат. Визуальная проверка — за пользователем; Storybook содержит `Default` и `ArtDirection`.
