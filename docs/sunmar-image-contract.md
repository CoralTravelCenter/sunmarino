# Изображение

Выводит изображение через `picture` и `img`. При заданном `srcset` добавляет один `source` для выбора другого файла браузером.

## Слоты

Слотов нет: содержимое задаётся атрибутами.

## Атрибуты

| Атрибут | Варианты / по умолчанию | Назначение |
| --- | --- | --- |
| `src` | URL / пустая строка | Основное изображение |
| `alt` | Текст / пустая строка | Описание изображения; для декоративного оставьте пустым |
| `width`, `height` | Числа от 1 / не заданы | Исходные размеры изображения; дробная часть отбрасывается |
| `srcset` | URL или список источников / пустая строка | Источники для одного `source`; пустое значение убирает `source` |
| `sizes` | Например `100vw` / не задан | Ожидаемая ширина изображения; работает с `srcset` |
| `media` | По умолчанию `(min-width: 768px)` | Условие выбора `source`; пустая строка снимает ограничение |
| `loading` | `lazy`, `eager` / решает браузер | Отложенная или немедленная загрузка |
