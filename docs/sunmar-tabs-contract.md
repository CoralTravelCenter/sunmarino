# Вкладки

Переключают связанные панели содержимого в одной области страницы.

## Слоты

| Компонент | Что передавать |
| --- | --- |
| `sunmar-tabs` | Непосредственные пары `sunmar-tab` и `sunmar-tab-content` с одинаковым `value`; служебные слоты назначаются автоматически |
| `sunmar-tab` / слот по умолчанию | Один непосредственный `<button type="button">` с названием вкладки |
| `sunmar-tab-content` / слот по умолчанию | Содержимое панели: заголовки, текст и другие элементы |

## Атрибуты

| Компонент / атрибут | Варианты / по умолчанию | Назначение |
| --- | --- | --- |
| `sunmar-tabs` / `value` | Строковый ID | Выбранная вкладка; без значения выбирается первая доступная пара |
| `sunmar-tabs` / `aria-label` | Текст | Доступное имя списка вкладок |
| `sunmar-tab` / `value` | Непустая строка | ID вкладки, совпадающий с `value` панели |
| `sunmar-tab` / `forced` | Присутствует / отсутствует | Начальный выбор этой вкладки; приоритетнее начального `value` контейнера |
| `sunmar-tab-content` / `value` | Непустая строка | ID связанной вкладки |
| Вложенный `button` / `disabled` | Присутствует / отсутствует | Сделать вкладку недоступной |

Атрибутами `selected`, `active` и служебными слотами управляет контейнер; вручную их задавать не нужно.
