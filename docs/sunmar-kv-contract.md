# Главный баннер

Показывает изображение с заголовком, текстом и действиями поверх него.

## Слоты

| Слот | Что передавать |
| --- | --- |
| `image` | Обычно `sunmar-image`; обязательный |
| `title` | Заголовок `h1`, `h2` или `h3` подходящего уровня; обязательный |
| `eyebrow` | Надзаголовок: `<span>` или `<p>`; необязательный |
| `text` | Описание в `<p>`; необязательный |
| `actions` | Кнопка, ссылка или `sunmar-button-group`; необязательный |

Слота по умолчанию нет.

## Атрибуты

| Атрибут | Варианты | Назначение |
| --- | --- | --- |
| `full-width` | Присутствует / отсутствует | Растягивает внутренний баннер до ширины окна, убирает скругление и ограничивает высоту 520px. Контент ограничен 1530px. По умолчанию выключен |

Изображение для разных экранов задаётся через `src`, `srcset` и `media` вложенного `sunmar-image`.
