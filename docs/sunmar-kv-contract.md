# Контракт sunmar-kv

## Назначение

Главный баннер с изображением и контентом поверх него. Компонент отвечает за CSS-раскладку и оформление. Внутренний корень — `section`. Публичных методов, событий и обработчиков нет.

## Attributes

| Атрибут | JS-свойство | Тип | Контракт |
| --- | --- | --- | --- |
| `full-width` | `fullWidth` | Boolean | Помечает KV как полноширинный, сбрасывает border radius его внутреннего корня и включает полноширинные стили внешнего контейнера. Значение атрибута не учитывается: `<sunmar-kv full-width>` и `<sunmar-kv full-width="false">` означают включённое состояние. Удаление атрибута или `fullWidth = false` возвращает базовое состояние. Атрибут и свойство отражаются друг в друга. |

Атрибут служит публичным маркером для внешнего layout. Поскольку Shadow DOM не может стилизовать предка компонента, внешний контейнер реагирует на него в глобальном CSS, например:

```scss
.row-container.layout-container-limit.center:has(sunmar-kv[full-width]) {
  /* полноширинные стили внешнего контейнера */
}
```

## Slots

| Slot | Требование |
| --- | --- |
| `image` | Обязательный: обычно `sunmar-image`; иной media-элемент должен сам заполнять область визуала |
| `title` | Обязательный: семантический заголовок с уровнем, подходящим странице |
| `eyebrow` | Необязательный: надзаголовок, обычно span или p |
| `text` | Необязательный: описание, обычно p |
| `actions` | Необязательный: кнопка, ссылка или группа кнопок |

Обязательность — требование к разметке потребителя, без runtime-валидации. Default slot отсутствует. Контент остаётся в light DOM: компонент не клонирует узлы и не генерирует заголовки или кнопки. Добавление, замена и удаление содержимого работают через нативные slots.

Пустые необязательные slots не создают собственного контента; контейнеры eyebrow и text сохраняются, но не имеют собственных вертикальных отступов. Отступы назначаются переданным элементам. Пустая переданная обёртка actions всё равно получает margin-top; её отсутствие и пустое содержимое не эквивалентны.

## CSS-контракт

Изображение расположено абсолютно на всю область баннера. Для `sunmar-image` передаётся `--sunmarino-image-height: 100%`, чтобы внутренние picture и img заполняли высоту. Позиционирование изображения настраивается через `--sunmarino-image-object-position`.

Компонент адаптируется к ширине окна через media queries. `aspect-ratio` задаёт предпочтительную пропорцию баннера; длинный контент может увеличить его высоту.

Actions получает отступ сверху 32px, сохраняя собственный display. Это позволяет непосредственно передать `sunmar-button-group` с его flex-раскладкой и адаптивной CSS-переменной направления.

| Ширина окна | Aspect ratio | Padding контента |
| --- | --- | --- |
| Меньше 768px | 87 / 113 | 48px 32px |
| От 768px | 608 / 320 | 48px 40px |
| От 1024px | 872 / 360 | 48px |
| От 1280px | 1120 / 400 | 48px 80px |
| От 1440px | 1360 / 500 | 48px 80px |

Заголовок: 40px, от ширины окна 1440px — 56px. Текст: 16px. Брейкпоинты используют общую SCSS-карту.

Публичные parts: `root`, `media`, `picture`, `content`, `content-inner`, `eyebrow`, `title`, `text`. Part `actions` отсутствует.

CSS-переменные: `--sunmarino-kv-content-color`, `--sunmarino-kv-content-max-width`, `--sunmarino-kv-eyebrow-color`, `--sunmarino-kv-title-color`, `--sunmarino-kv-text-color`. Цвет по умолчанию — системный светлый текст; максимальная ширина контента — 100%. Текущие общие типографические токены с двойными дефисами сохранены, их миграция в этот этап не входит.

`:host` отвечает за участие custom element во внешнем layout и наследуемые значения. `.root` отвечает за внутреннюю геометрию, clipping, aspect ratio и визуальную поверхность баннера. `full-width` используется глобальным layout-правилом и не смешивает стили внешнего контейнера с Shadow DOM компонента.

## Семантика и состояния

Потребитель задаёт уровень заголовка и alt изображения, а также обеспечивает читаемость текста на выбранном фоне. Загрузка изображения остаётся ответственностью `sunmar-image` и браузера. Фокус, клавиатура, disabled и действия принадлежат вложенным нативным элементам.

Компонент не создаёт listeners, observers, timers и внешних ресурсов. Повторное подключение сохраняет содержимое и обработчики потребителя.

## Пример

```html
<sunmar-kv full-width>
  <sunmar-image slot="image" src="/mobile.jpg" srcset="/desktop.jpg" media="(min-width: 768px)" alt=""></sunmar-image>
  <h1 slot="title">Отдых у моря</h1>
  <p slot="text">Выберите направление для отпуска.</p>
  <sunmar-button-group slot="actions" type="primary">
    <sunmar-button><button type="button">Подобрать тур</button></sunmar-button>
    <sunmar-button type="secondary"><a href="#details">Подробнее</a></sunmar-button>
  </sunmar-button-group>
</sunmar-kv>
```

## Проверки

Тесты happy-dom проверяют проекцию обязательного контента, отсутствие placeholders, динамические необязательные slots, сохранение группы кнопок и обработчиков при повторном подключении. Заполнение изображения, aspect ratio, flex-раскладка, адаптивность и читаемость проверяются пользователем в браузере, а не этими тестами.
