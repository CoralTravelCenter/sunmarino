# Библиотека компонентов Sunmarino

Это справочник по использованию компонентов и набор работающих примеров. Выберите компонент слева, прочитайте его «Документацию», затем откройте «Песочницу», чтобы проверить нужные настройки.

## Как пользоваться примерами

1. Откройте «Песочницу» выбранного компонента.
2. В панели **Controls** (параметры) измените текст, число или переключатель. Результат обновляется сразу.
3. У каждого поля есть пояснение. В таблице указано значение по умолчанию в библиотеке; начальные значения конкретного примера могут отличаться.
4. Чтобы вернуть исходные параметры примера, нажмите кнопку сброса в Controls.
5. Откройте остальные сценарии: они показывают конкретные способы интеграции. У этих примеров нет Controls, поскольку их разметка фиксирована.

В документации **Show code** открывает код примера. Для адаптивных сценариев меняйте ширину области просмотра. Карточка реагирует на собственную ширину; изображения, баннер, слайдер и навигация — на ширину окна примера.

Для проверки модального окна и длинной страницы навигации удобнее открыть отдельную историю на всю область просмотра. У модального окна и вкладок события отображаются под примером. Панель **Accessibility** помогает найти возможные проблемы доступности; дополнительно проверяйте клавиатуру и читаемость самостоятельно.

## Что означают группы параметров

| Группа | Что она меняет |
| --- | --- |
| Параметры компонента | Публичные атрибуты или JS-свойства компонента |
| Нативный элемент | Параметры вложенного `button` или `a`, а не оболочки |
| CSS-настройки | Публичные CSS-переменные оформления |
| Содержимое и настройки примера | Текст слотов, размеры демонстрационного контейнера и состав примера; это не дополнительные свойства компонента |

## Подключение на страницу

Подключите собранный файл библиотеки из каталога `dist`. Имя содержит версию пакета; используйте имя файла вашей сборки и путь, по которому он опубликован на вашем сайте.

```html
<script src="/assets/sunmarino-0.1.3.iife.js" defer></script>

<sunmar-button type="primary">
  <button type="button">Подобрать тур</button>
</sunmar-button>
```

Сборка регистрирует пользовательские элементы `sunmar-*` и подключает общие токены оформления. Шрифт на странице подключает принимающий сайт; Storybook подключает Museo Sans Cyrl отдельно для демонстрации. В проекте библиотеки команда `npm run build` создаёт сборку, а `npm run storybook` запускает этот справочник локально.

Если скрипт загружается асинхронно, перед обращением к свойствам и методам дождитесь регистрации компонента:

```js
await customElements.whenDefined('sunmar-modal');
const modal = document.querySelector('sunmar-modal');
modal.show();
```

## Атрибуты и свойства

Атрибуты пишутся в HTML, свойства задаются в JavaScript. Имена иногда различаются:

```html
<sunmar-slider slides-per-view="2" drag-free aria-label="Направления"></sunmar-slider>
```

```js
const slider = document.querySelector('sunmar-slider');
slider.slidesPerView = 2;
slider.dragFree = false;
```

У логических HTML-атрибутов важен факт присутствия. `open="false"` всё равно означает открытое состояние. Для выключения удалите атрибут или присвойте логическому JS-свойству `false`. Таблица каждого компонента объясняет, отражаются ли свойства обратно в HTML.

`reversed` у карточки — только CSS-атрибут: используйте `card.toggleAttribute('reversed', true)`. Свойства `card.reversed` в публичном API нет.

## Слоты: куда передавать содержимое

Слот — место для вашей HTML-разметки внутри компонента. Именованный слот выбирается атрибутом `slot` на непосредственном дочернем элементе:

```html
<sunmar-card>
  <sunmar-image slot="media" src="/coast.jpg" alt="Побережье" width="720" height="480"></sunmar-image>
  <h3 slot="title">Турция</h3>
  <p slot="text">Отдых у моря.</p>
  <sunmar-button slot="actions">
    <a href="/offers">Посмотреть предложения</a>
  </sunmar-button>
</sunmar-card>
```

Слот по умолчанию принимает содержимое без `slot`. Он есть не у всех компонентов. Содержимое остаётся в HTML страницы — это называется light DOM. Внутренняя разметка компонента находится в Shadow DOM: его стили изолированы от обычных селекторов страницы.

## Кнопки, ссылки и события

`sunmar-button` оформляет нативный элемент. Для действия используйте `button`, для перехода — `a`. Параметры формы и `disabled` задаются вложенной кнопке; `href`, `target` и `rel` — ссылке. Не добавляйте промежуточную обёртку между `sunmar-button` и нативным элементом.

```js
const button = document.querySelector('sunmar-button > button');
button.addEventListener('click', () => {
  // Выполните действие приложения.
});

const tabs = document.querySelector('sunmar-tabs');
tabs.addEventListener('sunmar-tabs-change', (event) => {
  console.log(event.detail.value, event.detail.previousValue);
});
```

Программное изменение `tabs.value` не создаёт пользовательское событие. У модального окна используются `sunmar-modal-open` и `sunmar-modal-close`. Служебные события не входят в контракт интеграции. Отсутствие публичных событий или методов явно указано на странице компонента.

## Оформление

Сначала используйте публичные CSS-переменные. Для точечного оформления внутреннего элемента применяйте опубликованные CSS-части — `::part(...)`:

```css
sunmar-button-group {
  --sunmarino-button-group-direction: column;
  --sunmarino-button-group-gap: 24px;
}

sunmar-image::part(img) {
  border-radius: 16px;
}
```

Названия тегов имеют префикс `sunmar-`, CSS-переменные и общие CSS-классы — `sunmarino-`. Не обращайтесь к внутренним классам Shadow DOM и служебным атрибутам. Список доступных переменных и CSS-частей находится в контракте компонента.

## Что проверить перед использованием

Заполните обязательные слоты, задайте подходящий уровень заголовка и осмысленный `alt` содержательным изображениям. Для декоративных изображений используйте пустой `alt`. Дайте доступное имя вкладкам, карусели и модальному окну. Проверьте сценарий с клавиатурой, длинным текстом и на узком экране.

Размеры кнопок `small`, `medium`, `large` сейчас поддерживаются в API и наследуются от группы, но выглядят одинаково: размерные стили ещё не реализованы. Загрузка изображений и движка карусели зависит от сети; при недоступности движка слайдер оставляет содержимое в статической сетке.
